# 写作小宇宙

面向人教版七年级英语教材的作文指导网页。内容覆盖七年级上册 3 个 Starter Unit 和 7 个正式 Unit，以及七年级下册 8 个 Unit；每个 Unit 都提供原创写作任务拆解、词句库、三段式提纲、例文、中文解析、个性化提纲、基础自检和拍照 AI 批改。

## 学习方式

页面提供“跟着步骤学”和“我已写完，拍照批改”两个入口。跟着步骤学习时，依次完成读题、搭建框架、参考仿写、独立完成和拍照批改五步；步骤、草稿和素材卡会按 Unit 自动保存在当前浏览器中，刷新或切换单元后可以继续学习。

## 本地打开

仅浏览作文指导内容时，直接双击 `index.html` 即可打开。

拍照 AI 批改需要通过本地服务运行，并使用你自己的 DeepSeek API Key：

```powershell
Copy-Item .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY
npm start
```

然后访问 `http://127.0.0.1:4173`。

也可不创建 `.env` 直接运行 `npm start` 检查网页；此时拍照批改会提示尚未配置密钥。

## 拍照批改流程

1. 选择当前作文对应的 Unit。
2. 上传清晰、正面、光线充足的作文照片，图片会先在浏览器中压缩。
3. 勾选授权提示后提交；图片只用于本次请求，不会被本地服务写入磁盘。
4. AI 返回英文转写、20 分制评分、逐处修改、七年级水平升级稿和下一步练习。

请勿上传含姓名、电话、住址、学号或其他敏感信息的照片。视觉识别可能出错，尤其是字迹模糊或拍摄倾斜时；请将反馈作为学习建议，并自行核对原文。

## AI 接口

服务端提供 `POST /api/review`。浏览器将上传图片数据和当前 Unit 的写作要求，服务端才会调用 DeepSeek Chat Completions API（`deepseek-flash` 支持图片识别）；API Key 只保存在服务端环境变量中，不会暴露到浏览器。

```json
{
  "imageDataUrl": "data:image/jpeg;base64,...",
  "unit": {
    "id": "u1",
    "title": "You and Me"
  }
}
```

默认模型为 `deepseek-flash`，可通过 `.env` 中的 `DEEPSEEK_MODEL` 覆盖。返回内容固定为评分、批改条目和升级稿，且会限制在本单元词汇、语法和建议字数内。

## 阿里云部署

1. 将项目上传到 ECS、轻量应用服务器或容器服务，并在服务器环境变量中设置 `DEEPSEEK_API_KEY`；生产环境不需要上传 `.env` 文件。
2. 平台会自动提供 `PORT` 时无需手动指定；服务默认监听 `0.0.0.0`，可通过 `HOST` 覆盖。
3. 使用 `npm start` 启动后，可访问 `GET /health` 检查服务状态；返回的 `aiConfigured` 仅表示是否已配置密钥，不会泄露密钥内容。
4. 建议通过 Nginx 或阿里云负载均衡提供 HTTPS，并将外网请求转发到本服务端口；不要在前端代码、镜像或公开仓库中写入 DeepSeek API Key。
